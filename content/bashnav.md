bashnav is a set of marine navigation tools written in POSIX shell and awk. The same tools run as web apps on the iPad, and once installed they keep working with no connection.

**Open it:** [bashnav.navigationtools.org](https://bashnav.navigationtools.org/)

## Installing on the iPad

1. Open [bashnav.navigationtools.org](https://bashnav.navigationtools.org/) in Safari, with a signal.
2. Open the tool you want, then tap **Share → Add to Home Screen**.
3. Open the tool once **from its Home Screen icon** while you still have a signal. An installed web app keeps its own storage, separate from Safari's, so this first opening is what makes it work offline.
4. Repeat for each tool you'll use at sea.
